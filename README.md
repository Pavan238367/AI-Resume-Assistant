# 🤖 AI Resume Analyzer

AI Resume Analyzer is a Flask-based web application that analyzes PDF resumes and provides detailed information about resume quality, ATS compatibility, and job matching.

## ✨ Features

- 📄 PDF Resume Upload
- 👤 Personal Information Extraction
- 💻 Skills Extraction
- 🎓 Education Extraction
- 💼 Experience Extraction
- 🔑 Resume Keyword Extraction
- ⭐ Resume Score
- 🤖 ATS Score
- 🎯 Job Match Score
- 💡 AI Suggestions
- 📝 Resume Summary
- 🛠️ Resume Improvement Analysis
- 📊 Resume Strength Breakdown
- 📋 Resume Analysis History
- 📈 Analytics Dashboard
- ⚖️ Resume Comparison
- 📄 PDF Report Generation
- 📱 Mobile Responsive Design
- 🔐 Basic Security Features
- ⚠️ Custom Error Handling

## 🛠️ Technologies

- Python
- Flask
- HTML
- CSS
- SQLite
- ReportLab
- Jinja2
