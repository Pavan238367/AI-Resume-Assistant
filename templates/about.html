🤖 About AI Resume Analyzer

📄 What is AI Resume Analyzer?

AI Resume Analyzer is a web application that analyzes resumes and provides useful information about resume quality, ATS compatibility and job matching.

✨ Features

  • 📄 Resume PDF Upload
  • 👤 Personal Information Extraction
  • 💻 Skills Detection
  • 🎓 Education Detection
  • 💼 Experience Detection
  • ⭐ Resume Score
  • 🤖 ATS Score
  • 🎯 Job Match Score
  • 🔑 Resume Keywords
  • 💡 AI Suggestions
  • 📝 Resume Summary
  • 📊 Resume Strength Analysis
  • 📋 Analysis History
  • 📈 Analytics Dashboard
  • ⚖️ Resume Comparison
  • 📄 PDF Report Generation

🎯 How It Works

  1. Upload your resume as a PDF.
  2. Enter the job description.
  3. Click Analyze Resume.
  4. The application extracts important resume information.
  5. Resume, ATS and job-match scores are calculated.
  6. Suggestions and improvement analysis are generated.
  7. You can view the results and download a PDF report.

🛠️ Technologies Used

  • 🐍 Python
  • 🌐 Flask
  • 🎨 HTML
  • 🎨 CSS
  • 🗄️ SQLite
  • 📄 ReportLab
  • 🤖 Jinja2
